About This Assignment

What special features have you done or attempted in creating the website?

  • Using bootsrtap as the CSS framework, so the page will be fully reponsive.
  • Auto-filled current date using PHP and made it editable.
  • Checked for duplicate status codes before inserting into the database.
  • Custom error messages that meet keyword and formatting requirements.
  • Automatically created the database table if it didn’t exist.
  • Implemented a reset feature to drop the table from the database.

Which part(s) did you have trouble with?

  • Regex validation for the status message with allowed symbols.
  • Handling the date format (`dd/mm/yyyy`) properly and making it editable.

What would you like to do better next time?

  • Use prepared statements for more secure database access.
  • Add client-side form validation for better user experience.
  • Implement user authentication and session management.
